read-me.txt

In the 1970s a terminal was an interface to a computer. It was a screen, a keyboard, and no mouse.

The modern terminal mimics that user experience. It's about using your computer with just a keyboard and memorized expertise.

In these few lessons you'll get introduced to the terminal: a tool coders love to use when working with AI.
