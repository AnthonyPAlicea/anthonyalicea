# The prompt

The same request is sent for every one of the sixteen generations. Only the context changes.

---

Build a single page where a customer can report a car accident to us.

It should collect everything we need to open the claim, and it should look like it belongs to our product. Keep it to one page.

---

Written the way a product manager actually writes it. It says what the business needs. It says nothing about who is filling it in or where they are standing when they do.
